# Diaporama de Stage - Développeur Web

## 📋 Description
Ce projet contient un diaporama interactif présentant mon stage de développeur web qui s'est déroulé du **13 mai au 27 juin 2024** (7 semaines).

## 🎯 Fonctionnalités
- **10 slides complètes** couvrant tous les aspects du stage
- **Navigation intuitive** avec boutons et touches du clavier
- **Design moderne** avec animations et transitions
- **Responsive** pour tous les appareils
- **Compteur de slides** pour suivre la progression

## 🚀 Utilisation

### Accès rapide
1. Ouvrir `index-sio.php` ou `index-sio.html` dans votre navigateur
2. Cliquer sur "🎯 Voir le Diaporama de Stage"

### Accès direct
Ouvrir directement `diaporama.php` dans votre navigateur

### Serveur local PHP
```bash
php -S localhost:8000
```
Puis aller sur `http://localhost:8000/diaporama.php`

## 🎮 Navigation
- **Boutons** : Précédent / Suivant
- **Clavier** : ← / → (flèches gauche/droite)
- **Compteur** : Affichage du slide actuel (ex: 1/10)

## 📊 Contenu du Diaporama
1. **Titre** - Présentation générale du stage
2. **Introduction** - Objectifs et contexte
3. **Entreprise** - Environnement professionnel
4. **Technologies** - Outils et langages utilisés
5. **Missions** - Tâches front-end et back-end
6. **Projets** - Réalisations concrètes
7. **Compétences** - Acquis techniques et professionnels
8. **Défis** - Problèmes rencontrés et solutions
9. **Résultats** - Accomplissements et métriques
10. **Conclusion** - Bilan et remerciements

## 🛠️ Technologies Utilisées
- **HTML5** - Structure du diaporama
- **CSS3** - Styles et animations
- **JavaScript** - Interactivité et navigation
- **PHP** - Intégration serveur

## 📝 Notes
- Diaporama optimisé pour présentation en plein écran
- Compatible avec tous les navigateurs modernes
- Aucune dépendance externe requise
